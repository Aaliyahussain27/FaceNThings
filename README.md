## FaceNThings

Real-time Face Detection + Object Detection using OpenCV and YOLOv8.
A lightweight computer vision project that runs entirely on your local webcam.


**Features**

-Real-time face detection using Haar Cascade

-Real-time object detection using YOLOv8

-Detects specific objects:

-Clean UI with bounding boxes + labels

-FPS-friendly and runs on CPU

**Tech Stack**

Face Detection ->	OpenCV (Haar Cascade)

Object Detection -> Ultralytics YOLOv8

Language ->	Python

Model ->	yolov8n.pt

Webcam Control ->	OpenCV
